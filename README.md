# Parallel-programming
# Лабораторная работа №1
**Цели данной работы:**
- Создание и отладка программы по перемножению двух квадратных матриц
- Проверка результатов с помощью стороннего ПО - Python
- Изучить результаты с разными видами матриц
- Подвести итоги

Ход работы:
- Начальная задача:
Написать программу на языке C/C++ для перемножения двух квадратных матриц.
Исходные данные: файл(ы) содержащие значения исходных матриц.
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи и др.
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

- Код для выполнения данной задачи:
**main.cpp - главный файл по выполнению данной задачи.**
Его работа разделена на следующие пункты:
- Создание двух файлов, для которых пользователь задаёт размер матрицы N, после чего они заполняются случайно числами от 1 до 100;
- Сбор данных файлов с матрицами в массивы данных и создание массива для заполнения числами в итоговый файл;
- Процесс перемножения матриц и вписывание массива с результатами умножения в результирующий файл;
- Вывод данных, разбираемых в нашем исследовании;
- Проверка и верификация результатов с помощью файла verify.py, выполняемого через Python.
